PLAYSTATION · PACKAGE INPUTS

PKG guide

PKG is a package container used by multiple PlayStation generations. The same extension does not make contents or workflows interchangeable across consoles.

PS3 and PS4 paths

The source catalog lists PS3 PKG and PS4 retail, Fake and split PKG formats. The workflow inspects package identity where supported and selects platform-specific tools and outputs. PS4 base/update rebuilding uses the FPKG workflow; retail signing is unavailable without Sony's private signing service.

Before processing

  • Use the correct platform's package and update files.
  • Keep the base and update from the same title and region/content identity.
  • Do not rename package files to disguise a mismatch.
  • Allow the application to verify the resulting output.

Common problems

  • Missing publishing or package tool: configure the existing project tool integration.
  • Wrong region or title ID: use a matching update.
  • Insufficient scratch space: choose a workspace with enough free capacity.
  • The extension alone does not prove package type, validity or suitability for a target.

For a PS4 Itemzflow folder pair, see the Itemzflow guide. To report a failure, attach a reviewed diagnostic log and search existing community reports first.
