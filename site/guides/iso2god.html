ISO2GOD guide

ISO2GOD converts a supported Xbox 360 disc ISO into a Games on Demand (GOD) folder layout. Digital Forge also catalogs Xbox 360 GOD, folder and split-ISO inputs.

Basic workflow

  1. Choose a local source file you own or are authorized to use.
  2. Use a supported Xbox 360 ISO or archive. Multipart archives must include all parts.
  3. Provide enough free space for extraction and output.
  4. Choose a local destination or a configured delivery target.
  5. Review the output verification result before transferring it.

Inputs and support

The repository documents Xbox 360 ISO and supported archive inputs, including ZIP/RAR and multipart archives where installed extraction tools support them. A complete multipart set must be present. Archive expansion and conversion can require substantially more storage than the compressed input.

Limits

This workflow does not bypass copy protection, download games or make an incompatible package playable. Use files you are authorized to use. The repository also contains historical Xbox store and FTP documentation; the current application may not expose every historical feature. Follow the actual application menus and release guide.
