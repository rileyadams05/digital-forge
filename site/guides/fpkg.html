PS4 FPKG guide

A Fake PKG is a PS4 package built with the configured homebrew packaging toolchain. Digital Forge exposes an FPKG workflow for supported PS4 inputs and can merge a validated base and update into one final package.

Supported paths

  • Build from supported PS4 game-folder inputs using the configured OrbisPkgTool workflow.
  • Prepare a matching update package and invoke the existing merge path when a compatible base/update pair is selected.
  • Use the Itemzflow parent-folder importer to discover a dumped base and patch together.

Validation and output

The workflow reads package/SFO identity, title ID, content ID and version metadata, validates base/update identity, stages source data in a workspace, builds required intermediate package inputs, runs the merge and validates the result. A successful run produces one final merged PKG. A failed merge or final validation must be reported as failure.

Tools and source handling

Tool selection follows the project's current configuration and executable discovery. The app does not download or replace CyB1K Fake PKG Tools. Generated projects and packages are written to temporary workspace; the original game folder is not used as the work directory.

Limits and troubleshooting

  • Retail PKG signing requires Sony's private signing service; this workflow cannot create a retail signed package from a folder.
  • Mismatched game/update identities are rejected.
  • Additional content is not generically folded into a base-game PKG.
  • For payloads over 50 GB, an internal PC workspace is recommended. External storage remains allowed.
  • On failure, read the reported stage and diagnostic log. Search existing reports before filing an issue.
