COMMUNITY REPORTS

Compatibility & support

Game results come from approved test records. GitHub Issues are reserved for games that were tested and failed.

Search a game

Choose Games on the home page and enter the game's ID. The website checks the approved successful-test list and searches GitHub Issues for failure reports. A failure report takes priority unless a newer successful test has been approved and published.

Successful tests

Successful results appear in the public catalog only after a project reviewer approves and merges the report. Do not submit successful tests as GitHub Issues.

Report a successful test

This page connects to GitHub automatically. Once connected, enter the game details and attach the Digital Forge game log. The website prepares a pull request in the project repository. Your report is published only after a project reviewer merges it.

The .log or .txt file is added to the pull request in the public Digital Forge repository, so it is visible to the public before and after review. Remove personal or device-identifying information first. Do not attach game files.

GITHUB ISSUES

Game not working?

Use the issue form for games you tested that failed to launch, crashed, or had a reproducible in-game problem. Include the game ID and test details. Review any log for personal information first; do not attach game files.

Report a game failure ↗
  • Unknown: no approved successful test or matching failure report is recorded.
  • Tested working: an approved website record confirms a successful test. Version and test environment may affect results.
  • Problem reported: a matching failure issue exists. We recommend not using the game until it has been fixed and a newer successful test is recorded.

Emulator compatibility sources

Digital Forge does not maintain emulator game-compatibility ratings. For emulator-specific results, check the emulator project's own compatibility list or issue tracker. Those results describe performance in that emulator; they do not verify Digital Forge processing or original-console compatibility.
